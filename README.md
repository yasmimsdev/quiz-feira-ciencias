1. o resultado quando vocês jogam acertando todas as 5 perguntas;
Placar final: 5 pontos.
Perfeito! Você é um expert em ciências!

2. o resultado quando vocês jogam acertando 3 perguntas;
Placar final: 3 pontos.
Bom trabalho! Você mandou bem.

3. o resultado quando vocês jogam errando todas;
Placar final: 0 pontos.
Que tal estudar mais um pouco?

4. o que acontece se colocarem a condição "pontos >= 1" antes de "pontos == 5";
Ele exibirá "Foi por pouco! Continue tentando." para todo resultado acima de 1, e não exibirá as frases corretas. 

5. por que as mensagens personalizadas precisam ficar depois do loop e não dentro dele.
